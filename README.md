# telemetrix

**TermSaver**: an ultra-lightweight terminal screensaver and live system
telemetry dashboard for Windows 11 and Linux, written in Rust. It shows CPU,
memory, swap, disks and temperature, plus cards from small Lua plugins, and it
aims to stay under 10 MB of RAM and near-zero CPU on static themes. Settings
live in a commented `telemetrix.toml` that a bad value can never break.

Work in progress.
